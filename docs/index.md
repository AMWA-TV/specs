# AMWA Specifications

Welcome to the home for specifications and technical documents from the [Advanced Media Workflow Association](https://www.amwa.tv/).

Use the sites below to browse the current AMWA documentation. Individual repositories are published at their own canonical `specs.amwa.tv` URL, while the indexes provide the best way to discover related documents.

## Networked Media Open Specifications

The [NMOS specifications index](https://specs.amwa.tv/nmos/) brings together the Networked Media Open Specifications, best practices, informative documents, and registers.

Browse the NMOS catalogue by:

- [Theme](https://specs.amwa.tv/nmos/by-theme/)
- [Document type](https://specs.amwa.tv/nmos/by-type/)
- [Tag](https://specs.amwa.tv/nmos/tags/)
- [Global documentation search](https://specs.amwa.tv/nmos/global-search/)

The NMOS site also includes [background documentation](https://specs.amwa.tv/nmos/Documentation/), including an introduction, technical overview, FAQ, glossary, and NMOS solutions.

## AMWA Increments

[AMWA Increments](https://specs.amwa.tv/in-index/) are snapshots of ongoing AMWA activity phases. The Increment index links each published document to its repository and current documentation site.

## AS-11 specifications

The [AS-11 specifications](https://www.amwa.tv/as-11) define MXF contribution file formats for delivery of finished media assets.

## Find a specification

For a known document, use its canonical site directly. Common examples include:

- [IS-04 — Discovery and Registration](https://specs.amwa.tv/is-04/)
- [IS-05 — Device Connection Management](https://specs.amwa.tv/is-05/)
- [IS-08 — Audio Channel Mapping](https://specs.amwa.tv/is-08/)
- [BCP-003 — API Security](https://specs.amwa.tv/bcp-003/)
- [NMOS Parameter Registers](https://specs.amwa.tv/nmos-parameter-registers/)

If you are not sure which document you need, start with the [NMOS index](https://specs.amwa.tv/nmos/) or the [global documentation search](https://specs.amwa.tv/nmos/global-search/).
